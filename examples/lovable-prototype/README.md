# Lovable / Bolt Prototype Example

Shows how to add Pinflow to a typical vibe-coded prototype generated by Lovable, Bolt, or similar tools. One script tag, no framework integration needed.

## Run

```bash
npx serve .
```

Share `http://localhost:3000/?reviewer=Stakeholder` for feedback.

## Why this matters

Lovable and Bolt generate complete HTML/CSS/JS prototypes. Adding Pinflow is a single line — no need to touch the generated code structure, install npm, or configure a build tool.
